## Checklist

1. Run the doc gate first; spend your own effort on what it cannot check —
   symbol identity, duplication, scope creep.
2. Read every in-scope file; build the claim-set (paths, symbols, constants,
   targets, links) and verify each against the tree, the refs tool over raw
   grep.
3. Auto-apply, conservatively: a verified dead reference (cut), an exact
   duplicate (one home plus a pointer), an orphan pointer whose target is
   found (repoint), a tombstone describing absent code (cut if verified).
4. Report, never apply: `CLAUDE.md` scope creep, a rule or agent restating
   another, any cut to a contract paragraph — as a severity-rated table in
   `docs/reviews/<YYYY-MM-DD>-doc-hygiene.md`, file:line, what is wrong, the
   action.
5. Lean is the goal, not minimal: a line that earns its place stays.
6. Sanity-check the edits (no dangling section refs or orphaned index rows);
   leave the diff uncommitted; a mere sync gap is noted for tech-writer;
   report your token cost.
