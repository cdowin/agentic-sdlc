## Ship criterion — MET, all thirteen clauses

The reviewer could not construct an accepted `--skip` that fails to print its own line, and the reason
is structural rather than incidental: `skippable_for` refuses any `skippable` entry not in
`[<op>] steps`, so `declared` is a subset of `names`, so an accepted skip is always a name the print
loop walks. **A silent skip is unreachable.**

All four config refusals and all four flag refusals probed live — exit 2, by name, nothing written,
and the skipped check never called. Stock is byte-identical: diffed against `a05a378`'s driver, the
only two changes are the new `skipped:` line, which fires only on a skip, and the `adopt` census,
which renders its old string verbatim when nothing was skipped. `--force` is untouched and the two
records do not bleed into each other.

**The D12 revision is honest.** D5 breaks exactly one clause — a skipped check is not run — and says
so in the decision, in the docstring and in `--help`. One write, every check named, false-and-silent
still writes nothing, and a refused close leaves no judgement behind: all verified.
