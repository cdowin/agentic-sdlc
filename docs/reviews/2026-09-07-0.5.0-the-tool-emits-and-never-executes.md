## Attacking the claim: twelve ways to put execution on the emit path

Each variant is a doctored copy of `emit.py`, run through the SHIPPED helpers
(`conftest.module_spawns`, `_execution_sites`, `_imported_modules`, `EMIT_MUST_CALL`), never the
working tree.

| attack | caught by |
|---|---|
| `import subprocess` at module level | `module_spawns`, import allowlist |
| `import subprocess` **inside a function** ("we only do it lazily") | `module_spawns`, import allowlist (`ast.walk`, not `tree.body`) |
| `import os` + `os.system(cmd)` | `_execution_sites`, import allowlist |
| `import os as _o` + `_o.system(cmd)` | import allowlist (alias-proof: it matches the MODULE name) |
| a new sibling `repo/runner.py` holding the spawn | import allowlist |
| `importlib.import_module(sink)` | `_execution_sites`, import allowlist |
| `importlib.metadata.entry_points(group=…)` — D1's rejected discovery | `_execution_sites`, import allowlist |
| `getattr(mod, sink)()` | `_execution_sites` |
| the file emptied to a docstring | `EMIT_MUST_CALL` (rule 4's floor) |
| the file renamed or moved | `assertIn(EMIT_MODULE, _sources())` |
| `Path(sink).open('w')` | **not** by this class — caught by primitive 2 (`test_only_the_apply_module_writes`) in the same file |
| `sys.modules['subprocess'].run(cmd, shell=True)` | **nothing** — N1 |

So the answer to "does the test forbid it or merely document it" is **forbid**: every route that
reads as a convenience is a build break named by `file:line`, and the two survivors are a write (a
different primitive already owns it) and a deliberate reach through `sys.modules`.
