  * **R1 (MAJOR).** Three live instances of F1's class, none of which I found by reading — the gate
    found all three the moment it existed. `steps._record_of` and `report.py` each spelled the escape
    check as `startswith('/')`, which reads `../outside.md` as repo-relative and resolves it anywhere.
    `pm feature done --review-record` checked **no escape at all**: it verified the file RESOLVED, so
    a path outside the checkout that happens to exist could be stamped onto a grain. All routed
    through `model.pointer_escapes`.
  * **R2 (MAJOR).** `model.py:2544` carried a byte-for-byte hand-rolled copy of `record_path`'s body
    (`Path(pointer) if pointer.startswith('/') else cfg.root / pointer`) — the one-resolver rule
    broken inside the module that defines the resolver. Routed.
  * **R3 (MAJOR, DEFERRED).** The collect-and-render primitive did not land. It is the largest of the
    three consolidations, touches every read verb at once, and the feature's own text warns that a
    grand unification in one pass is how a framework acquires a second scoreboard. The tree already
    carried five other features from today. The two that shipped each have a 0.5.0 finding as their
    test case; the primitive's argument is maintainability, which is real and not urgent. Recorded in
    the grain rather than left as a silence.
  * **R4 (WARNING).** My first gate flagged `ready_for._pointer_defect` as an offender. It is not: it
    is strictly RICHER, naming which shape is wrong ("is a URL", "is home-relative", "a backslash is
    not a path separator") where the predicate answers yes/no. Exempting it would have been a hole,
    so instead it is bound — `test_the_richer_classifier_never_disagrees_with_the_predicate` asserts
    the two readers agree on the verdict for every shape. Two readers of one question that can
    disagree is the `at`/`ts` defect.
