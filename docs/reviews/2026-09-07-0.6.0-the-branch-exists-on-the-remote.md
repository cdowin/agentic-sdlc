## The reversal, and it is the finding worth keeping

The first implementation ran `git rev-list --count HEAD --not --remotes` and `git log --format=%ct`
to deliver the count and age the ship criterion asks for. It worked. `make unit` then failed **235
cases** in the `not shell` tier, each by nodeid, each saying *tried to spawn a process* —
because `census()` is called by every `pm` write and by `check pm`, so a git call there puts a
subprocess on the hot path of verbs whose entire contract (hard rule 2) is that they boot nothing
and are safe in parallel.

**Prose would not have caught this. The tier derivation did, mechanically, by nodeid.** That is the
milestone's own thesis landing on the milestone's own work.

The reader was rewritten to read `.git/HEAD`, `refs/`, `packed-refs` and `config` as text. It
answers *published* and *in sync* exactly and **does not answer how far ahead**, because that needs
a graph walk. D3 on the milestone records the rejected alternatives.

## What was probed, and what bit

| probe | result |
|---|---|
| `git pack-refs --all` after a push | **BIT.** A reader of `refs/remotes/` alone calls a packed pushed branch *unpushed* and tells the operator to push work already safe. `_packed()` exists for this; `test_a_PACKED_remote_ref_still_counts_as_published` asserts the ref really was packed first, so the case cannot pass vacuously. |
| `iterdir()` over `refs/remotes/` | **BIT.** `test_boundaries.py::OneWalk` failed it — enumeration belongs to `core/walk.py`. Replaced with remote NAMES read from `.git/config` and one targeted probe each; no enumeration at all. |
| detached HEAD | Returns None. There is no branch to be behind. |
| no remote configured | Returns None, and every surface is silent. Quiet, not broken. |
| pushed-then-advanced | `published=True, in_sync=False` — the two facts stay separate, so the line never says "on no remote" about a branch that is on one. |
| a grep for `subprocess`/`git_lines`/`popen` in the module | `test_the_reader_SPAWNS_NOTHING`. The cheapest thing that can fail, and it is the contract the 235 failures bought. |
