## The design decision worth recording

**Contracts are POINTED AT, never copied**, and this was the one real choice. Copying would put a
163-line paste in every brief; the milestone's own constraint says the answer is placement, not
volume. Pointing means the agent must open the file — one tool call, after the "first tool call" the
ship criterion names.

Taken deliberately: the measured failure in 0.5.0 was not that agents disobeyed the rules, it was
that **they had no signal the rules existed**. A named pointer fixes exactly that, and it cannot
drift. `test_the_contract_is_POINTED_AT_and_never_copied` plants a 40-line contract body and asserts
none of it reaches the output.
