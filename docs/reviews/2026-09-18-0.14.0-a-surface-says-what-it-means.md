## Blockers

- **M1 MAJOR** `src/agentic_sdlc/repo/install.py:149`: the declared-pattern fallback puts the pattern into a
  single-quoted YAML scalar and does not escape it. `_yaml_scalar` escapes only VERSION_FILE. Probe:
  `version_file = "src/pkg/__init__.py"`, `version_pattern = "^__version__ = '(.*)'$"`. This is a common
  Python shape, and `_ere_of` accepts it. The result is `VERSION_PATTERN: '^__version__ = '(.*)'$'`, exit 0,
  and `[install] wrote .github/workflows/semver-gate.yml`. A YAML parser then fails with `did not find expected
  key ... line 31`, so GitHub cannot load the workflow. This is a write that looks legitimate and is not. Fix:
  double each `'` in the pattern (`pattern.replace("'", "''")`). Add a `'` case to the existing parametrize in
  `tests/test_ci_workflows.py::test_the_verb_writes_the_whole_set_and_a_diff_round_trips_clean`.

## Findings

- **W1 WARNING** `pm/roadmap/features/ft-a-surface-says-what-it-means.md:10`: the changelog says
  `make pm|sdlc ARGS=…` "accepts `'` as typed". It does not. A lone `'` exits 2 and prints the `\'` hint,
  which is what the brief asked for. The changelog also does not say that the recipe shell no longer reads
  ARGS. Probe: `ARGS='list | grep foo'` now gives the argv `list | grep foo`, and before it ran a pipe. `$VAR`,
  globs, `>` and `;` also pass as literal text now. No file in this repo puts an operator inside ARGS
  (I searched with grep). Fix: reword the changelog. Say that `'` is written `\'`, and that ARGS is now
  arguments only, with no shell operators.
- **W2 WARNING** `src/agentic_sdlc/repo/installables/ci-auto-tag.yml:33`: `auto-tag.yml` still reads a
  hardcoded `pyproject.toml`. On a `project.godot` tree it fails with a clear message, so it does not lie.
  But the install-ci notice at `install.py:325` says both workflows read `[pm] version_file`, and #51 will
  recur for this file. Fix: add the same `BODIES` entry. The brief covers only the semver gate, so this
  finding goes to the orchestrator to disposition.
- **N1 NIT** `src/agentic_sdlc/repo/conveyor/steps.py:1023`: when the gate names another file, adopt prints
  the generic `differs`. It does not say that VERSION_FILE is not `[pm] version_file`. The check fails, which
  is what the brief asks for, and `install-ci --diff` shows the line. I accept this as is.
- **N2 NIT** `src/agentic_sdlc/repo/dispatch.py:343`: `verdict.VERDICTS[1]` selects the example verdict by
  its position in the list. Name the constant instead.

Probes that passed: ARGS with `(` and `,`; a `$`, `$(HOME)`, a backtick and `$$` all pass as typed (before
this change `$5` disappeared). Empty or whitespace-only ARGS falls back to `--help`, for both `pm` and `sdlc`.
`#12` is no longer a comment. The sub-make sees `ARGS` unset, `MAKEFLAGS` empty and `AGENTIC_SDLC_ARGS`
popped. A yml file has no config block, so `--force` replaces the whole gate and adopt cannot grade a stale
env line as header-only. A version file with no pattern is graded `unrenderable` by adopt, which counts as
drift.

Not verified: `make test` (the integration tier), and the rendered gate on GitHub Actions.
