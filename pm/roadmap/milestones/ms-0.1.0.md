# 0.1.0 — the agentic half standing alone

## What shipped, and under which version

0.1.0's work is in the mainline: `7ae552e Green the suite, self-install, and start 0.1.0`
and `cb37e51 Merge pull request #1 from cdowin/setup/0.1.0-standing-alone`. The package
stood alone, the suite was green and it self-installed — which is what this milestone was
named for.

**There is no `v0.1.0` tag.** The work went out inside the **`v0.2.0`** release, so this
milestone finished without ever being cut as a release of its own. It is `done`, not `obe`:
the work happened and was delivered, just under someone else's version.

Closed 2026-09-06 by `0.3.0/bugs/the-first-milestone-never-closed`, which is the finding R4
and R6 raised on their first run against this tree — the record had said `planning` for two
